# ASR-arxiv-daily

自动追踪 arXiv 上的自动语音识别与语音转文字论文。

[使用与部署说明](./docs/README.md#usage)

> 尚未抓取论文。运行 `python daily_arxiv.py` 或启动 GitHub Actions 后自动更新。

每 12 小时检索一次，按首次提交日期倒序排列，历史论文会持续保留。

代码链接来自论文中的 GitHub 地址或按 arXiv ID 检索的候选仓库，未经人工确认。
